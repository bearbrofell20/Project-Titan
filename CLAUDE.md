project and applies to every agent working here.**

Quick orientation:
- **Mission:** find a statistically defensible trading edge; run it on paper.
- **Prime directive:** never manufacture a result, never claim certainty, always
  report negative findings honestly.
- **Before proposing any strategy:** check §5 (settled results) so you don't
  re-test what is already answered, and §6 (known traps) so you don't repeat a
  mistake that already cost us weeks.
- **Before shipping anything:** it must clear the §8 checklist.
